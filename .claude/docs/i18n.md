# Internationalisation (i18n) — Référence

---

## Configuration

**Langue principale** : Français (fr)
**Langue secondaire** : Anglais (en) — pour les clients internationaux
**Bibliothèque** : vue-i18n v9

**Règle** : toutes les chaînes visibles par l'utilisateur passent par `$t()`. Jamais de texte codé en dur dans les templates Vue.

---

## Configuration vue-i18n

```typescript
// src/i18n/index.ts
import { createI18n } from 'vue-i18n'
import fr from './fr'
import en from './en'

export const i18n = createI18n({
    legacy: false,           // Composition API
    locale: 'fr',            // Langue par défaut
    fallbackLocale: 'en',    // Fallback si clé manquante
    messages: { fr, en },
    numberFormats: {
        fr: {
            currency: {
                style: 'currency', currency: 'XOF',
                minimumFractionDigits: 0, maximumFractionDigits: 0,
            },
            percent: { style: 'percent', minimumFractionDigits: 1 },
        },
        en: {
            currency: {
                style: 'currency', currency: 'XOF',
                minimumFractionDigits: 0,
            },
        },
    },
    datetimeFormats: {
        fr: {
            short:    { day: '2-digit', month: '2-digit', year: 'numeric' },
            long:     { day: '2-digit', month: 'long', year: 'numeric' },
            datetime: { day: '2-digit', month: '2-digit', year: 'numeric', hour: '2-digit', minute: '2-digit' },
            time:     { hour: '2-digit', minute: '2-digit' },
        },
    },
})
```

## Convention des clés

```
{namespace}.{section}.{element}

Exemples :
  common.actions.save            → "Enregistrer"
  common.actions.cancel          → "Annuler"
  common.status.active           → "Actif"
  rooms.status.available         → "Disponible"
  rooms.status.occupied          → "Occupée"
  reservations.actions.checkin   → "Enregistrer l'arrivée"
  billing.labels.total           → "Total TTC"
  errors.conflict                → "Cette chambre est déjà réservée"
```

## Usage dans les composants Vue

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'
const { t, n, d } = useI18n()
</script>

<template>
  <!-- Texte simple -->
  <button>{{ t('common.actions.save') }}</button>

  <!-- Avec variable -->
  <p>{{ t('reservations.confirm.checkin', { guest: 'Amadou Diallo', room: '312' }) }}</p>

  <!-- Pluralisation -->
  <span>{{ t('reservations.labels.nights', reservation.nights) }}</span>

  <!-- Formatage montant XOF -->
  <span>{{ n(135000, 'currency') }}</span>
  <!-- → 135 000 F CFA -->

  <!-- Formatage date -->
  <span>{{ d(new Date('2026-05-12'), 'long') }}</span>
  <!-- → 12 mai 2026 -->
</template>
```

## Changement de langue

```typescript
// src/stores/auth.store.ts
// Persister la préférence de langue du staff
import { useI18n } from 'vue-i18n'

const { locale } = useI18n()

function setLocale(lang: 'fr' | 'en') {
    locale.value = lang
    localStorage.setItem('locale', lang)
}

// Au login, charger la préférence depuis le profil staff
// StaffUser.locale → 'fr' | 'en'
```
